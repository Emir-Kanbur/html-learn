# HTML Öğrenme Notları

HTML öğrenme sürecinde hazırladığım örnekler, notlar ve mini alıştırmalar.

## İçerik

- `YOBU/ilk-uygulama.html` — kişisel sayfa için ilk HTML örneği.

## Kullanım

HTML dosyasını indirip bir web tarayıcısında açabilirsiniz. Projeyi çalıştırmak
için ek bir bağımlılık veya derleme adımı gerekmez.
